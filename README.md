### 🇷🇺 Русский

Легковесный и надежный агент для мониторинга состояния Docker-контейнеров, отслеживания статусов Docker-демона и удаленного выполнения команд. Разработан на языке Go, работает напрямую через официальный Docker API и низкоуровневые системные вызовы. Является частью экосистемы HostPulse CRM. 

### ✨ Особенности

* ⚡ **Минимальные ресурсы**: благодаря компиляции в бинарный код на Go, агент потребляет всего до 15-20 МБ оперативной памяти и имеет околонулевую нагрузку на процессор.
* 📦 **Развертывание одной командой**: поставляется в виде изолированного Docker-контейнера на базе Alpine Linux (размер образа ~20 МБ).
* 🔒 **Абсолютная прозрачность**: код полностью открыт. Системные администраторы могут провести аудит безопасности в любой момент.

### 📊 Функционал

1. **Слежка за контейнерами** — моментальная фиксация падений (exited), остановок и автоматических перезапусков контейнеров на хосте с мгновенной отправкой алертов в CRM.
2. **Мониторинг Docker-демона** — проверка доступности, стабильности и аптайма среды Docker на целевом сервере.
3. **Удаленные команды** — безопасный прием, валидация и выполнение административных команд из CRM (только при успешной проверке секретного пароля).

### 🛠 Быстрый запуск

Для полноценной работы агенту необходим прямой доступ к Docker-сокету хост-машины, поэтому в команде запуска обязательно монтируется ключ -v /var/run/docker.sock:/var/run/docker.sock. 

Выполните команду на вашем целевом сервере (все переменные генерируются вашим Telegram-ботом CRM автоматически): 

bash

docker rm -f docker-agent || true && docker run -d \
--name docker-agent \
--restart unless-stopped \
-v /var/run/docker.sock:/var/run/docker.sock \
-e HOSTPULSE_API_URL="https://host-pulse.zedform.kz/api/v1/agent/events/" \
-e HOSTPULSE_TOKEN="your-server-uuid-token" \
-e HOSTPULSE_SECRET="your-secure-password" \
ghcr.io/host-pulse/hostpulse-docker-agent:latest


### 🇬🇧 English

A lightweight and reliable agent for monitoring Docker container statuses, tracking Docker daemon health, and executing remote commands. Built with Go, it interacts directly with the official Docker API and low-level system calls. It is a native part of the HostPulse CRM ecosystem. 

### ✨ Features

* ⚡ **Ultra-low Footprint**: Uses less than 15-20 MB of RAM due to pure Go compilation, with near-zero CPU overhead.
* 📦 **One-Command Deployment**: Packaged as an isolated Docker container based on Alpine Linux (image size is ~20 MB).
* 🔒 **Secure & Open**: Open-source code ensures absolute transparency and easy security audits for system administrators.

### 📊 Functionality

1. **Container Tracking** — Real-time detection of container crashes (exited), stops, and restarts on the host, with instant alert dispatching to the CRM.
2. **Daemon Health** — Monitoring the accessibility, stability, and uptime of the host's Docker environment.
3. **Remote Commands** — Secure reception and execution of administrative tasks triggered from the CRM (validated via secure password).

### 🛠 Quick Start

The agent requires direct access to the host machine's Docker socket, so mounting -v /var/run/docker.sock:/var/run/docker.sock is strictly mandatory. 

Execute the following command on your target server (variables are automatically generated by your Telegram CRM Bot): 

bash

docker rm -f docker-agent || true && docker run -d \
--name docker-agent \
--restart unless-stopped \
-v /var/run/docker.sock:/var/run/docker.sock \
-e HOSTPULSE_API_URL="https://host-pulse.zedform.kz/api/v1/agent/events/" \
-e HOSTPULSE_TOKEN="your-server-uuid-token" \
-e HOSTPULSE_SECRET="your-secure-password" \
ghcr.io/host-pulse/hostpulse-docker-agent:latest


### 🇰🇿 Қазақша

Docker контейнерлерінің күйін, Docker демонының денсаулығын бақылауға және командаларды қашықтан орындауға арналған жеңіл әрі сенімді агент. Go тілінде жасалған, ресми Docker API және төмен деңгейлі жүйелік шақырулар арқылы тікелей жұмыс істейді. HostPulse CRM экожүйесінің бөлігі болып табылады. 

### ✨ Ерекшеліктері

* ⚡ **Минималды ресурстар**: Бинарлы кодқа компиляциялану арқасында бар болғаны 15-20 МБ-қа дейін жедел жадты тұтынады және процессорға салмақ түсірмейді.
* 📦 **Бір командамен орнату**: Alpine Linux негезіндегі оқшауланған Docker контейнерінде жұмыс ішійді (образ өлшемі ~20 МБ).
* 🔒 **Қауіпсіздік пен ашықтық**: Жүйелік әкімшілер тарапынан қауіпсіздік аудитін өткізу үшін код толықтай ашық.

### 📊 Функционалы

1. **Контейнерлерді қадағалау** — хосттағы контейнерлердің құлауын (exited), тоқтауын және қайта іске қосылуын лезде тіркеп, CRM-ге жедел ескертулер жіберу.
2. **Docker демонын бақылау** — хост-машинадағы Docker ортасының қолжетімділігін, тұрақтылығын және жұмыс уақытын бақылау.
3. **Қашықтағы командалар** — құпия парольді тексере отырып, CRM-ден жіберілген әкімшілік командаларды қауіпсіз қабылдау және орындау.
